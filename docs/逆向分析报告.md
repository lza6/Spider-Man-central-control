# 蜘蛛侠中控（Spider-Man Central Control）逆向分析报告

## 1. 目标文件
- **文件**: 蜘蛛侠中控.exe
- **格式**: PE32 托管程序（.NET）· VB.NET · CLR 4.0 · WinForms
- **程序集**: XXTCC 1.0.1.0
- **保护**: DNGuard 混淆（类型/方法重命名 + #US 字符串堆移位混淆 + 内嵌资源重打包）

## 2. 软件性质
iPhone 越狱设备**群控 + TikTok 批量养号工具**（XXTouch 生态）。
```
蜘蛛侠中控.exe (PC, Nancy HTTP :27010)
   │ SSH / TCP / WebSocket(46268) / HTTP(46952)
   ├── iPhone(XXTouch) × N  ← 运行 TKZK.xxt Lua 脚本
```

## 5. 授权机制
- **scriptauthorization.* 授权SDK**，服务器 `xxtauth.ttaozi.com` / `xxtauth.sozereal.com`(80)
- 参数: `dids / sns / ts / sign / v` → `POST /api/devices_info` 校验 `expireDates`；另有 `/api/bind_code` 绑定设备
- 签名常量 `8d4d305a0725b8e9bc1faa765a013a7362d03f72` + HMACSHA256
- TKZK.xxt 尾部含 **X.509 证书签名块**（Devices / X.X.T / Auth），需私钥才能重签

## 7. 功能"用不了"根因诊断（E2E 实测）
控制端 Nancy HTTP 服务已实测 **7/7 接口全部通过**：
```
[PASS] Nancy HTTP 存活        GET /          -> 200 Hello Nancy And XXTouch
[PASS] getui 任务轮询          GET /getui     -> 200 {}
[PASS] 账号表读取             POST /db/list  -> state 0
[PASS] 登录账号读取            POST /db/list  -> state 0
[PASS] 本地账号读取            POST /db/list  -> state 0
[PASS] 日志上报               POST /log      -> ok
[PASS] 文件读取               POST /file/take_line -> 200
```
**根因**: 无 iPhone 真机上线（config.json `Devices:[]`）→ 设备列表空 → 养号/关注/登录/上传等全部功能无执行对象 → getui 无任务可发。

**次要因素**:
1. 授权: 需有效 AuthKey 绑定设备（未绑定会受限）
2. 脚本分发: TKZK.xxt 须先同步至手机 `1ferver/lua/scripts/`

**恢复正常使用的必要条件**:
1. 越狱 iPhone 安装 XXTouch + 运行本脚本
2. 手机与 PC 同局域网，脚本 `CC.connect(PC_IP, 27010)` 上线
3. PC 设备列表出现设备 → 勾选 → 运行养号等功能

## 8. 安全风险提示
- 仓库内含**真实账号凭证**（TikTok session / Outlook 邮箱密码 / 2FA），一旦泄露可被完全接管
- PC 27010 端口无认证，局域网内任意设备可读写数据库/文件
- 批量养号违反 TikTok 社区规则，存在封号风险
