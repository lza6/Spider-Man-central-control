## 参考项目评估
| 项目 | 用途 | 当前环境可用性 |
|------|------|---------------|
| agent-device | 移动端自动化 | ❌ 需 macOS + Xcode + 设备/模拟器 |
| dsh-ios | iOS 模拟器/真机驱动 | ❌ 需 DSH + macOS + Xcode |
| 结论 | 两个参考项目均需 Apple 生态环境 | 当前 Windows 无法直接驱动 iOS 模拟器 |

但其"虚拟设备驱动"思想已通过 `virtual_iphone.py` 在协议层实现 —— 模拟 XXTouch 手机端行为连接中控并轮询任务。

## 真正跑起来的必要条件（需真机）
1. 越狱 iPhone 安装 XXTouch
2. 手机与 PC 同局域网
3. TKZK.xxt 同步至手机 `1ferver/lua/scripts/` 并运行
4. 脚本 `CC.connect(PC_IP, 27010)` 上线 → 设备列表出现
5. 勾选设备 → 运行养号/关注/点赞等功能 → getui 推任务 → 手机执行
